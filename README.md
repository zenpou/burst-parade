# BURST PARADE — LAST FREQUENCY

海賊ラジオのDJ・アカリが、閉局間際の回線で海底線の非常ベルを拾う。音響技師ミオと元指揮者セナを乗せ、朝までに街の声を取り戻す、Windows用1人プレイ横スクロールSTG。

## 遊び始める

[最新のWindows版をダウンロード](https://github.com/zenpou/burst-parade/releases/latest/download/BurstParade-Windows-x64.zip)し、ZIPをすべて展開して、中の `BurstParade.exe` を起動します。タイトルでEnter、放送卓で操縦士と章を選び、もう一度Enterで会話と出撃へ進みます。

| 場面 | 操作 |
| --- | --- |
| 放送卓 | ↑↓またはW/Sで章、←→またはA/Dで操縦士を選ぶ。Enterで回線を開く。章・操縦士・ボタンはクリックでも選択可能 |
| 通信 | Enter・Spaceまたは下半分をクリックして次の台詞へ。Tabで会話送り。分岐は左右で選び、Enterか選択肢のクリックで決定 |
| 戦闘 | WASD・矢印で移動。正面へ自動射撃。ゲージ満タンでSpaceを押すとバースト |
| ボスとの交信 | 戦闘は一時停止。Enter・Space・クリックで返答し、交戦開始。Tabで交信をスキップ |
| イベントCG | クリア後に帰投通信を開くと、主人公とその章のライバルの一枚絵を表示。Hで台詞や枠の表示を切り替え |
| 放送アルバム | 放送卓でG。解放したCGを左右キーか前後ボタンで鑑賞。Enter・Escで放送卓へ戻る |
| 一時停止 | Escで停止・再開。停止中のTabで放送卓へ戻る |
| 結果 | Enterで帰投通信または同じ章に再出撃。Tab・Escで放送卓へ |
| 個人放送 | その操縦士で任意の章をクリアすると、放送卓のRまたは個人放送ボタンで解放された短編を読める |
| 共通 | Mで消音、Fで演出の強弱を切り替え。弱では揺れと必殺カットインを止め、火花を減らす |

## 5つの放送局

| 章 | 舞台 | ボス | 後半の攻撃 |
| --- | --- | --- | --- |
| 1 | 第七埠頭 | 灯台を守るナギ / MANTA | 狙い弾に交差する扇状弾が加わる |
| 2 | 海底環状線 | 最後尾の車掌スズ / LEVIATHAN | 3列の平行弾が線路をつくる |
| 3 | 浮遊温室群 | 蘭の記録係リラ / ORCHID | 回転する花弁状の弾幕 |
| 4 | 軌道昇降塔 | 軌道通信士トワ / GEMINI | 上下二つの発射点から交差射撃 |
| 5 | 中央放送聖堂 | 放送人格イオ / CODA | 4拍目に静止して広い扇状弾を放つ |

各ライバルは自分の武装で画面に登場します。交信で守りたいものを語り、戦闘の後半には固有の台詞と予告演出があります。放送アルバムは保存済みの章クリアスコアを参照するため、旧版でクリアした章のCGも鑑賞できます。

飛行中は操縦士の腰元にある白い円弧が敵弾に当たる範囲を示し、中央の黄緑の光がその中心です。背景は右から左へ流れ、手前の構造物ほど速く通り過ぎます。

1.75秒以内に続けて敵を倒すとチェインが伸び、得点倍率は最大8倍。バーストで敵弾を消し、画面内の敵をまとめて攻撃できます。ボスに通常弾を当ててもゲージを充填できます。

アカリは直線の高速連射、ミオは三方向の拡散弾、セナは盾にもダメージを通せる重いランスを使います。セナは第3話の帰投通信後に加入します。道中の通常敵は10種。分裂機は撃破後に小型機を放ち、突撃機は照準を固定してから加速します。

第3話の救援回線選択で、後半2章の戦闘支援と結末が変化します。各章のスコアと耐久は出撃ごとにリセット。解放済みの章、帰投通信の再開地点、選択した回線、各章ベスト、個人放送、到達した結末はこのPCに保存します。別の結末は第3話を再プレイして回線を選び直せます。

## Unityで編集

Unity HubでこのREADMEのあるフォルダーを追加し、Unity **2022.3.35f1** で `Assets/Scenes/Parade.unity` を開いて再生します。メニュー **Burst Parade → Build Windows Player** の標準出力先は `Build/BurstParade.exe` です。

日本語の台本は `Assets/Game/Broadcast.cs`、敵編隊と機体性能は `Assets/Game/Combat.cs`、キャンペーン進行は `Assets/Game/Station.cs` にあります。生成画像は `Assets/Resources` に収録しています。[画像の制作指定](ART_DIRECTION.md)

## GitHub Actions でのビルドとリリース

`Windows build and release` は、ラベル `burst-parade-unity-windows` のWindowsランナーでUnityを起動し、チェックアウトしたソースからWindows x64版をビルドします。実行ファイルでキャンペーンとセーブ再開の自動テストを通した後、ZIPとSHA-256を作成します。

リリース担当者は、Unity 2022.3.35f1とWindows Build Supportを用意し、Unityを起動できるアカウントでリポジトリ専用ランナーを接続します。1回だけ接続する場合は、Settings → Actions → Runners → New self-hosted runner のWindows用登録コマンドに `--ephemeral --labels burst-parade-unity-windows` を付け、`run.cmd` を起動します。

Actionsタブの手動実行ではビルド成果物を取得できます。`v1.0.0` 形式の新しいタグをpushすると、テスト済みの同じZIPをGitHub Releaseに掲載します。次のビルド時にも同じラベルのランナーを起動してください。
